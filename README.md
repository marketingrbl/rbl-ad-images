# Reka & Bina Lab — finished ad images

**Public on purpose.** Meta and Google can only fetch pictures from a public web link, so
finished ad artwork is published here for them to pull.

This repository holds **finished ad pictures only** — the same pictures that run publicly on
Facebook and Instagram. Nothing else belongs here: no photo library, no drafts of other kinds,
no business documents, no project files. The project itself is a separate, private repository.
